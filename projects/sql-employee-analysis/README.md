# 🗄️ SQL | Employee & Salary Analysis

## 📌 Project Overview

SQL project focused on analyzing employee, salary, department and management data.

The project includes business-oriented queries involving salary analysis, employee distribution, management history and comparisons between employees and departments.

---

## 🎯 Analysis Tasks

The project includes queries to:

- Analyze average employee salaries by year
- Calculate average salaries by department
- Analyze department salaries over time
- Identify departments with the largest number of active employees
- Find managers based on employment duration
- Compare employee salaries with department averages
- Rank employees using Window Functions
- Analyze management history within departments

---

## 🛠️ SQL Skills Used

- JOIN
- CTE (Common Table Expressions)
- Subqueries
- Window Functions
- Aggregations
- GROUP BY / HAVING
- CASE
- Date Functions
- Ranking Functions
- Filtering and Sorting

---

## 💡 Key Concepts

The project demonstrates the ability to:

- Work with multiple related tables
- Build multi-step analytical queries
- Aggregate and compare employee data
- Use CTEs and subqueries to structure complex queries
- Apply Window Functions for ranking and comparative analysis
- Translate business questions into SQL queries
